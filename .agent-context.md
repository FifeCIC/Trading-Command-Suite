# Agent Context - Trading Command Suite

## What is this project?

**Trading Command Suite** is a production-ready React PWA for executing SEES (Scoring Engine Execution System) trading strategies. Built with React 18, Vite, TanStack Query, and Zustand.

**Not a WordPress plugin** - This is a standalone React application. TradePress (WordPress) is a separate project.

## Key Architectural Patterns

### State Management
- **Server State**: TanStack Query (5s polling, caching)
- **Client State**: Zustand (strategies, UI state)
- **Never**: Direct API calls from components

### Data Flow
- Background queue → Cache/Store → UI components
- No inline API calls during render
- Explicit data mode labels (Live/Cached/Queued/Demo)

### Core Systems
- **Protocols + Directives**: the signal thesis — protocols scope symbols/direction/timeframe;
  directives are individual scoring indicators (RSI, MACD, custom)
- **Trading Bots** (`TradingStrategy` rows): execution policies (money mgmt / risk / gates). See
  `docs/trading-bot-model.md` — "the whole pipeline is the strategy" (Protocol + Bot)
- **Backend**: NestJS (port 3201) under `nest/` — not "Trader.CORE"
