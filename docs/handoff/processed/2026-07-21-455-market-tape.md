**Date:** 2026-07-21

**Issue:** [#455](https://github.com/FifeCIC/Trading-Command-Suite/issues/455)

## What Changed

### Configurable Sections (⚙ button)
- A gear icon appears on the right side of the tape. Clicking opens a dropdown with checkboxes for all 8 sections:
  - Sessions, Events/Timeline, Provider Health, Automation Pulse, Next Session (default ON)
  - News Headline, Recent Trade, App Uptime (default OFF)
- Preferences persisted in `localStorage` key `tcs:market-tape`
- All sections hidden shows a hint: "All sections hidden — click ⚙ to configure"

### 3 New Data Sections

**📰 News Headline** (`prefs.news`)
- Data from `GET /api/news/feed?limit=1`
- Shows latest headline truncated to 80 chars
- Query disabled when section is toggled off (saves network)

**↕ Recent Trade** (`prefs.trade`)
- Data from `GET /api/providers/mt5/history?limit=1`
- Shows direction (BUY/SELL), symbol, and color-coded P&L (green/red)
- Query disabled when section is toggled off

**⏱ App Uptime** (`prefs.uptime`)
- Data from `GET /api/health` → `uptime` field
- Formatted as "Up 2d 3h 15m" or "Up 3h 15m"
- Query disabled when section is toggled off

### Existing 5 Sections Now Toggleable
All 5 original sections (Sessions, Events, Providers, Automation, Next Session) can be individually toggled via the preferences panel. They remain ON by default to preserve the existing experience.
